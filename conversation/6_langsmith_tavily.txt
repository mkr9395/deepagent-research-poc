  How to run one comparison

  .venv\Scripts\python main.py -v "Compare Microsoft and Alphabet on revenue
  growth, profitability, risks and outlook"
  Check that .env contains LANGSMITH_TRACING=true and your LANGSMITH_API_KEY.
  When the run ends you should see LangSmith trace sent to project '...'. If
  that line is missing, tracing is off or the key is unset. -v is optional and
  adds the console logs.

  Open the project, then Tracing, and click the run named financial-comparison.

    (fin_agent/agents/orchestrator.py#L165) only rejects an empty report or one
    with no http source URLs.
